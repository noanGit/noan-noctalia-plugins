# Noctalia Plugins

## Usage:

Download raw code, unzip archive and put the folder into `~/.local/state/noctalia/plugins/sources/*user_folder*`, so it should be like `~/.local/state/noctalia/plugins/sources/*user_folder*/repo/...`
Then add this folder as a source inside of noctalia/plugins and then configure it in plugins/widget settings
